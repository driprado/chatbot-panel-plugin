# Chatbot Panel Plugin

Grafana panel plugin that renders a chatbot-style UI for dashboards.

## Development

1) Install dependencies

yarn install

2) Build in development (watch)

yarn dev

3) Build for production

yarn build

## Testing

Run unit tests with Jest:

yarn test

End-to-end tests (Playwright):

yarn e2e
